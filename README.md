# SynVideoDownloader
Scrapes a designated URL for a video and downloads it.

Requires the .NET 10 SDK to build. Selenium.WebDriver uses Selenium Manager to resolve the Microsoft Edge driver automatically. Internet access or a cached driver is needed on the first run.

Supported Websites:
- [Youtube](https://www.youtube.com/)
- [Twitch Clips](https://www.twitch.tv/timthetatman/clip/ArbitraryImportantPoxNononoCat)
- [Streamable](https://streamable.com/fhfo5m)
